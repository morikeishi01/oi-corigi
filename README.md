# Đi Chợ — Ngân Sách Gia Đình

App theo dõi chi tiêu cho gia đình 2 người tại Nhật.
Mục tiêu: ¥100,000/tháng siêu thị + ¥16,691 Amazon.

## 🚀 Đưa lên GitHub Pages (3 bước)

### Bước 1: Tạo repo trên GitHub
1. Vào https://github.com/new
2. Đặt tên repo: `di-cho` (hoặc tên bạn muốn)
3. Chọn **Public**
4. Không tick gì cả, bấm **Create repository**

### Bước 2: Upload file
Sau khi tạo repo, GitHub sẽ hiện hướng dẫn. Làm theo cách **upload an existing file**:
1. Bấm link **uploading an existing file**
2. Kéo thả file `index.html` vào
3. Bấm **Commit changes**

### Bước 3: Bật GitHub Pages
1. Vào tab **Settings** của repo
2. Menu trái: **Pages**
3. Source: chọn **Deploy from a branch** → branch **main** → folder **/ (root)**
4. Bấm **Save**
5. Đợi 1-2 phút, link sẽ hiện: `https://YOUR_USERNAME.github.io/di-cho/`

## 🔒 Cách dùng
- **Lần đầu**: Tạo mã PIN 4 số
- **Các lần sau**: Nhập PIN để vào app
- **Quên PIN**: Bấm "Quên mã PIN?" (sẽ xóa hết dữ liệu)
- **Backup**: Vào tab Cài đặt → Xuất dữ liệu → lưu file JSON
- **Restore**: Vào tab Cài đặt → Nhập dữ liệu → chọn file JSON
